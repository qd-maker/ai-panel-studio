# AI 圆桌演播厅 · 25 秒演示片源文件

概念：「一束追光贯穿全片」。整片只有一束琥珀色的光（`#f5b841`，产品里唯一的强调色，只给"正在发生"的东西）：
它先是话题输入框里的光标，回车后分成五束点亮阵容，讨论中在发言人之间跳，跳过的路径拉直成立场光谱的横线，
最后落进总结页的首字下沉，再变成片尾字标旁边的那个点。一镜到底，没有转场切换，每个段落交界都由这束光带过去。

界面是按 `docs/images/` 和 `frontend/src/` 的样式用 HTML 重建的，不是录屏。文字全部来自一次真实的 DeepSeek 运行：
`backend/data/live/after-id-rule/raw.json` → `detail.participants / utterances / insights / summary`。
较长的发言只截取一个分句（开头标"……"）。

## 文件

| 文件 | 作用 |
|---|---|
| `comp.html` | 合成页面：每一帧都是 `t` 的纯函数，`window.__seek(t)` 定位任意时刻；`?play` 实时播放，`?t=9.6&hud` 定格 |
| `motion.js` | onetake 动作库（弹簧、跳跃、相机、抖动等），原样复制 |
| `look.json` → `look.js` | 产品色板 + 字体；`look.js` 由 onetake `look.py apply` 生成，内嵌 Inter / Geist Mono / Noto Sans SC 子集（均为 SIL OFL 1.1），保证 `file://` 渲染中文正确 |
| `score.py` → `sfx.wav` | 音效：读取 `comp.html` 的 `window.__events()` 定时和声像，全部合成（无音乐、无采样，无授权问题）；`events.json` 是导出的事件表 |
| `demo.render.json` | 渲染记录（帧数、快门、采样数），`verify_promo.py` 用它判断有没有运动模糊 |

## 重新生成

```bash
# 需要 Python 3.11 + playwright 1.63 + numpy scipy pillow fonttools brotli（建议放在项目外的独立 venv）
SK=~/.claude/skills/onetake/scripts
python -X utf8 $SK/look.py apply look.json comp.html --cjk C:/Windows/Fonts/NotoSansSC-VF.ttf   # 改了文案后重跑
python -X utf8 score.py                                                                        # → sfx.wav
python -X utf8 $SK/render.py comp.html --out build/demo.mp4 --sfx sfx.wav --crf 20 --gap 14 --samples-max 36   # 1080p30，180° 快门，8 进程约 3.5 分钟
python -X utf8 $SK/verify_promo.py build/demo.mp4 --comp comp.html --shots 0,1.0,3.05,5.15,7.35,9.4,10.6,11.4,14.2,17.0,20.8
# verify 要读 build/demo.render.json（和片子放一起）；通过后把 demo.mp4 拷到 docs/media/
```

GIF（≤ 8 MB）：10 fps、960 宽、hqdn3d 去噪、截 0.3–23.2 s；调色板 = 片子自动取 52 色 + 五位嘉宾色和琥珀色各 3 档手动钉住
（不钉的话嘉宾色面积太小会被调色板丢掉，头像环全变灰），`paletteuse=dither=none`。

## 声音

只有合成音效，同一个混响空间：打字是轻木头声（三下取一到两下），光的跳跃是一口随画面声像移动的气声，落点是圆润的泡声，
回车 / 落入首字 / 片尾字标三处用低频的闷击。静止段保持安静。峰值 −8 dBFS。
